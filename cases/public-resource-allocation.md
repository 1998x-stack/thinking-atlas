# 公共资源分配：定向消费券与献血制度的不同问题

**状态：研究工作表。** 当前主要依据本周题目与部分提问，尚未对具体项目规则和实际事件完成独立核实。

## 消费券：把“寻租空间”转为可检验的提问

某项目的商户准入是否透明？是否出现可证实的利益冲突、异常资金集中和缺少救济渠道？需要取得发放目标与预算、入围条件、申请及驳回记录、核销金额、关联交易规则和审计结果。公开透明、覆盖广且可审计的定向政策可能有可论证的目标；“定向”本身不等于已发生违法或寻租。

## 无偿献血：另建制度个案

可见索引仅表明曾询问“中国无偿献血制度”。后续应分别研究制度目标、采供流程、用血分配、费用结构、供需信息、地区差异与适用时期的法规；不能把资源的行政配置直接当作违规证据。

两者的资源属性、伦理要求及法域不同，可以共用准入/审计的取证工具，不能复制事件结论。[主模型](../domains/institutions/resource-gates.md)。
