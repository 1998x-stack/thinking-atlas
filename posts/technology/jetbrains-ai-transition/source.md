# JetBrains 首次亏损：IDE 的黄昏，还是工程智能的黎明？

研究整理日期：2026-11-25。

## 来源语境
[原知乎讨论（2026-11-24）](https://www.zhihu.com/question/2106013584778175176/answer/2108685699734041892) 提出传统 IDE 受 AI Agent 冲击、AI 成本和静态分析能力重新定价等观点。本文为独立研究整理，不转载原文；完整分析见 index.html，逐项来源及边界见 evidence.json。

## 研究问题
- 2025 年亏损究竟对应哪个法人及财务口径？营业利润、财务费用与税项如何变化？
- AI 成本、搬迁及 Fleet 投入有无可定位的财务归因？
- PSI、LSP、静态分析和 Agent 的关系是替代还是互补？
- 多厂商 Agent 基础设施能否形成可持续商业模式？

## 核心判断与限度
单体净亏损不等于集团亏损，不能把亏损全部归因于 AI；从人类 IDE 入口向 Agent 工具层迁移属于战略假设。原始财报、附注与集团数据仍待获取。交互模型为教学情景，不是实测经营数据。
