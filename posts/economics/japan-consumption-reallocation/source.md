# 日本长期停滞与逆势产业：消费结构迁移、零售革命及中国的适用边界

> 研究状态：partial｜资料核验截至 2026-11-22。本文把 1990 年代泡沫破裂后的零售结构变化，与 2020 年代日本当前消费数据分开处理，不把不同年代、不同统计口径拼成一条连续增长故事。

## 一、执行摘要

“经济下行时哪些行业反而增长”是一个容易被讲成行业神话的问题。日本案例确实显示，在收入预期转弱、价格竞争加剧和零售制度变化的时期，折扣零售、便利店、药妆、食品零售等业态可以获得份额；但这不意味着某些消费品在整个失落三十年里都按固定比例暴涨，也不意味着销售额增长就等于利润增长。

本研究得到五个结论：

1. **日本 1990 年代的零售变化有直接数据支持。** OECD《日本经济调查 1995》记录，1992 年以后折扣店销售额以每年约 10% 的名义速度增长；非食品折扣店份额从 1988 年的 4.2% 升至 1993 年的 5.6%；1991—1993 年男装折扣店销售额增加 28%，百货店男装销售额下降 15%。[S1]
2. **不能把零售转型全部归因于经济衰退。** OECD 同时讨论了大型零售店法规放松、渠道效率、批发层级、厂商控制和门店规模变化。经济压力是需求侧因素，竞争和制度改革是供给侧因素。[S1]
3. **“日本失落三十年”不是一个静止的宏观阶段。** 日本银行 2024 年研究把 1990 年代停滞与温和通缩、2010 年代复苏但通胀目标难以实现、2020 年代劳动力市场趋紧和进口价格冲击下的工资—价格变化区分开来。[S2]
4. **2025 年零售业态数据呈现分化，而非所有低价渠道一齐增长。** 日本经济产业省统计显示，2025 年零售额为 157.508 万亿日元，同比增长 1.4%；药妆店销售额增长 5.5%，超市增长 4.7%，便利店增长 3.4%，百货店下降 1.8%，家居中心下降 0.2%。[S3]
5. **名义增长不等于真实消费量增长。** METI 对 2025 年销售额作价格与数量分解：食品零售价格因素上升，但数量因素呈下降趋势；药妆店则是价格和数量因素共同推动增长。行业判断必须拆分价格、销量、门店数、单店销售和毛利。[S3]

因此，更准确的命题不是“经济下行必然让某些行业暴涨”，而是：**收入预期、人口结构、相对价格和渠道效率发生变化时，消费者会在品类、品牌、规格、渠道和购买时点之间重新分配支出。** 这是一种消费结构迁移，而不是所有行业共同的消费升级或消费降级。

## 二、研究范围与口径

本文使用三组不同时间窗口：

- **1990 年代初期：** 泡沫经济破裂后的需求疲弱和零售制度改革，主要使用 OECD 1995 年原始调查。
- **1990 年代至 2010 年代：** 长期通缩预期、零售促销和消费习惯变化，使用日本银行研究及同行评审论文。
- **2025 年：** 当前零售业态和价格—数量变化，使用日本经济产业省商业动态统计。

三组资料不能直接拼接成“1990—2025 年某行业累计增长”。各自的调查范围、名义/实际价格、业态分类和样本方法不同。尤其要区分：

- 销售额（sales value）与销售数量（volume）；
- 名义增速与扣除物价后的实际增速；
- 行业整体销售额与单店销售额；
- 销售额与营业利润、现金流和资本回报；
- 行业扩张与企业竞争优势。

## 三、1990 年代日本：折扣零售崛起有何证据？

OECD 1995 年报告提供了一组值得保留的历史数据：

| 指标 | 观察结果 | 正确解释 |
| --- | ---: | --- |
| 折扣店销售额 | 1992 年以后年均名义增长约 10% | 不是实际销量增速，也不是利润增速 |
| 非食品折扣店市场份额 | 1988 年 4.2%，1993 年 5.6% | 份额提升，不代表整个行业绝对规模无限扩张 |
| 男装折扣店销售额 | 1991—1993 年增加 28% | 特定品类和渠道的销售变化 |
| 百货店男装销售额 | 1991—1993 年下降 15% | 同一时期渠道之间出现替代 |
| 雇员超过 20 人的门店数 | 1991—1994 年增加 22% | 大型零售业态扩张，不能仅用消费降级解释 |
| 平均门店面积 | 1991—1994 年增加约 18% | 规模经济与渠道组织变化 |

[S1]

这组数据的关键并非“消费者突然不买东西”，而是消费者开始更认真地比较价格，传统零售商的渠道组织和定价方式受到挑战。折扣店能够通过更直接的采购、更少的中间环节和更高的周转效率提供更低价格。百货店依赖批发商、制造商和长期供货关系的模式，在价格竞争加剧时显得不够灵活。[S1]

### 3.1 需求侧：收入预期与价格敏感度

经济增长放慢、资产价格下跌和工资预期改变，会让家庭重新评估大额、可延后和可替代消费。消费者可能继续购买服装、食品和日用品，但会改变：

- 是否购买高端品牌；
- 是否等待促销；
- 是否转向自有品牌或低价渠道；
- 是否减少购买频率或降低规格；
- 是否把线下购物转为线上比价；
- 是否把非必需消费推迟到未来。

这意味着“需求没有消失”不等于“总消费不受影响”。有些需求被压缩，有些需求转移渠道，有些需求被推迟，还有些需求因为相对价格下降而获得销量。

### 3.2 供给侧：零售制度和渠道效率

OECD 把大型零售店法规放松、门店规模增长、传统分销结构和折扣渠道扩张放在同一背景下讨论。大型门店扩张和折扣店增长不仅是需求变化的结果，也改变了零售商之间的竞争方式。[S1]

这点对解释日本案例非常重要：如果只说“经济差，大家买便宜货”，就会遗漏一个更深层机制——**需求转弱会提高消费者对价格的敏感度，而竞争制度和渠道效率决定哪些企业有能力把这种敏感度转化为市场份额。**

## 四、失落三十年并不是一条直线

日本银行 2024 年研究回顾了过去 25 年的经济和价格变化：

- 1990 年代，日本经济陷入停滞和温和通缩，需求与供给两侧因素共同作用，货币政策受到名义利率下限约束。
- 2010 年代，量化和质化宽松等政策推动经济恢复，经济不再处于通缩状态，但工资和价格难以上升的行为惯性仍然存在。
- 2020 年代，疫情后经济恢复、劳动力市场趋紧和进口价格上升，使工资与价格之间的正向循环重新显现。[S2]

这意味着同样是“日本经济”，1995 年、2005 年、2015 年和 2025 年的消费者环境并不相同。把 1990 年代的折扣店案例直接当作 2025 年日本所有消费行业的增长规律，会产生明显的时间错配。

## 五、2025 年日本零售业：谁在增长，增长来自哪里？

日本经济产业省《2025 年小売業販売を振り返る》显示：

| 业态 | 2025 年销售额同比 |
| --- | ---: |
| 零售业整体 | +1.4% |
| 药妆店 | +5.5% |
| 超市 | +4.7% |
| 便利店 | +3.4% |
| 大型家电专门店 | +4.1% |
| 百货店 | -1.8% |
| 家居中心 | -0.2% |

[S3]

药妆店增长也不是简单的“大家生病了”或“大家只买便宜货”。METI 资料显示，药妆店销售额增长 5.5%，门店数增长 3.6%；食品销售额增长 9.1%，食品约占药妆店销售额的三分之一，调剂药品也贡献了增长。[S3]

更重要的是，2025 年食品零售销售额的价格因素上升，而数量因素总体走弱。也就是说，食品销售额增加可能同时伴随消费者购买数量减少。药妆店的价格和数量因素则都在增长，说明不同业态的增长机制不同。[S3]

**行业研究不能只看销售额同比。** 至少要同步查看价格指数、实际销量、门店数量、单店销售额、客单价、毛利率、库存周转和租金人工成本。

## 六、消费结构迁移的六种机制

### 6.1 同一品类内的品牌降档

消费者仍然购买洗衣液、食品、服装和日用品，但从高价品牌转向中价或自有品牌。品类需求还在，品牌结构改变。

### 6.2 从“买商品”转向“买便利”

便利店、即时零售、预制食品、外卖和小包装商品可能受益于时间稀缺、家庭规模变小和单人消费增加。但便利服务通常需要支付渠道、配送和人工成本，销量增长不保证利润更高。

### 6.3 从百货和专卖渠道转向折扣与高效率渠道

消费者对价格更加敏感时，低成本采购、快速周转、供应链短、商品结构清晰的渠道更容易获得份额。1990 年代日本折扣店的增长正是这一机制的历史例子。[S1]

### 6.4 从可选消费转向健康、护理和基础服务

老龄化可能增加慢病管理、护理用品、辅助器具、药品和健康服务的长期需求。但这类行业受医保支付、监管、劳动力供给和服务质量约束，不能只凭人口年龄结构推断盈利能力。

### 6.5 维修、二手、租赁与延长使用寿命

在耐用品价格较高、收入预期不确定时，消费者可能推迟换新、维修旧物、购买二手商品或租赁设备。其市场机会来自存量资产维护，而不是新购需求持续扩张。

### 6.6 促销常态化和购买时点迁移

关于日本“失落年代”销售促销的同行评审研究发现，促销频率在长期中增加，折扣幅度却下降；促销销售数量与常规价格销售数量的比率大体稳定，促销收入占总收入的比例从 1990 年代约 20% 上升至 2000 年代约 30%。[S6]

这意味着消费者可能越来越习惯等待促销，但零售商不一定因此获得更高利润。促销也可能只是把原本会发生的购买从一个时间点移到另一个时间点。

## 七、对流传数字的审查：啤酒、威士忌、酸奶、速冻食品

网络文章经常引用“日本啤酒下降 62%、威士忌下降 64%、酸奶增长 195%、速冻食品增长 178%”等数字。若没有原始表格、年份、产品分类、价格口径和样本范围，无法确认这些数字是否来自同一统计体系。

至少要核对五个问题：

1. 是销售额、销量、家庭购买量还是人均消费量？
2. 是 1990 年与 2020 年比较，还是某个低点与高点比较？
3. 是名义金额还是不变价数量？
4. 是全国家庭消费，还是特定年龄、家庭规模或零售渠道？
5. 产品分类是否发生变化，例如“乳制品”“酸奶饮料”“冷冻食品”是否被重新定义？

因此，本文不将这些数字列为已核实事实。若无法取得原始统计表，应该标注 UNVERIFIED，而不是通过转述次数把它们变成事实。

## 八、对中国的启示：可以迁移机制，不能照搬行业名单

日本经验可用于提出中国市场的假设，但不能直接给出中国未来的赢家名单。

| 可迁移机制 | 中国可能观察的领域 | 必须验证的变量 |
| --- | --- | --- |
| 价格敏感度上升 | 折扣店、社区超市、自有品牌 | 复购率、毛利、单店坪效、租金 |
| 家庭规模变化 | 小包装、即时零售、便利食品 | 单人家庭占比、客单价、配送成本 |
| 健康与老龄需求 | 药店、护理用品、康复和适老服务 | 支付能力、医保规则、服务人员供给 |
| 延迟换新 | 维修、二手、租赁、翻新 | 交易信任、质保、残值、获客成本 |
| 渠道效率提升 | 供应链直采、仓储会员店、低成本零售 | 周转率、库存损耗、供应商议价权 |
| 促销常态化 | 电商、直播、品牌折扣 | 促销后毛利、退货率、客户终身价值 |

中国与日本的差异包括人口结构、城镇化阶段、房地产资产负债表、互联网平台、社会保障、供应链成本和地方消费能力。日本 1990 年代的零售竞争发生在不同制度和渠道环境下，不应被机械复制。

## 九、如何识别真正的逆势机会？

建议用五个指标判断一个行业是否真的逆势，而不是仅仅名义销售额增加：

1. **真实需求：** 销量、购买频次或用户渗透率是否上升，而非单纯涨价。
2. **客户支付能力：** 客户是否有持续支付能力，而不是一次性促销购买。
3. **毛利与现金流：** 销售增长是否带来经营现金流改善。
4. **竞争结构：** 增长是否集中在少数高效率企业，还是所有企业都在价格战中扩张。
5. **需求可持续性：** 增长来自人口和生活方式的长期变化，还是临时补贴、库存周期或疫情后回补。

一个行业可以销售额增长、利润下降、现金流恶化。也可以整体行业萎缩，但头部企业凭借效率提升获得市场份额。投资或创业时应当研究企业的竞争位置，而不是只看行业故事。

## 十、结论

日本长期停滞时期确实出现了折扣零售、促销常态化和零售渠道重组，但这些变化同时受经济需求、法规改革、供应链结构、人口变化和企业效率影响。

因此，经济下行并不会自动创造“逆势行业”。更准确的解释是：当收入预期和相对价格改变时，消费者会在品牌、规格、渠道、购买频率和购买时点之间重新分配支出。真正能够逆势发展的企业，是那些能够用更低成本、更高周转、更可信服务或更适配的人群需求，持续满足客户的新选择的企业。

## 十一、研究限制与待补证据

- OECD 1995 的折扣店数据是历史名义销售额和市场份额，不能直接与 2025 年 METI 业态数据做长期增速比较。
- METI 的零售统计主要从供给侧观察销售额；不能替代家庭微观消费调查，也不能直接推导企业利润。
- 药妆店和超市增长受到门店数量、食品价格和人口结构共同影响，不能全部归因于经济衰退。
- 流传的啤酒、威士忌、酸奶和速冻食品增减幅度未找到完整原始口径，暂列 UNVERIFIED。
- 中国市场的行业机会需要省市、城市层级和消费人群的微观数据进一步验证。
