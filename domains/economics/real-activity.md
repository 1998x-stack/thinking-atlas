# 真实经济活动：多指标交叉验证

**材料来源**：现有一份名为《李克强一生分析.txt》的文本正文主要讨论经济指标与“李克强指数”扩展，不是人物生平；文内数字和外链本轮未逐一核实。[来源说明](../../sources/README.md)。

## 关键区分

（A）指标生成时有多少真实物理、支付或第三方记录约束；（B）指标与目标经济概念的映射是否稳定且代表总体。这两个问题不能合并；“难造假”不等于“足以代理 GDP”。

可以交叉观察用电、物流、银行卡消费、公积金实际缴存、税票、工程机械遥测、镜像贸易、卫星夜间灯光，但必须先写明：测的是工业活动、正规就业、消费渠道、住房交易，还是整体经济。

| 候选指标 | 测量对象 | 主要限制 |
|---|---|---|
| 公积金实缴人数 | 纳入缴存制度的人群 | 覆盖、缴存比例及政策变化 |
| 用电量 | 能源需求 | 天气、电气化和产业结构 |
| 银行卡消费 | 特定支付渠道的消费 | 支付渠道迁移及分类 |
| 货运与快递 | 货物流动 | 货品价格、结构及重复运输 |
| 契税和实际成交 | 特定房产交易 | 税率优惠、地区差异、滞后 |
| 夜间灯光 | 地表照明 | 服务业覆盖不均及技术变化 |

原材料提出的主观指标权重和“硬度”星级只是研究设想，不能写为通过样本外测试的指数。

## 本周七月/八月统计问题

先确定年份、发布日期、原始统计表、同口径基数和价格变化，再拆就业、消费、投资、住房等领域，最后以独立序列交叉验证。现有索引仅有题目，不能据此填写当月结果。
