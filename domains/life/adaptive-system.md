# 个人适应系统：能力、作品、关系和选择权

**来源**：《人生的适应系统.txt》《人生适应系统解析.txt》的共同主题；这是材料中原则的整理，不把个人经验写成对所有人无条件成立的定律。[材料映射](../../sources/README.md)。

## 主要操作原则

| 原则 | 行动方法 | 修正与边界 |
|---|---|---|
| 分类问题 | 分清可以解决、需要管理、必须接受、应考虑退出 | 退出要评估安全、支持与替代方案；不能机械要求立刻离开 |
| 行动换反馈 | 可逆事项制作低成本的最小版本 | 高代价、难逆决策先核查并控制损失 |
| 把能力外化为作品 | 围绕可交付结果定向学习和修订 | 作品不保证市场回报；检验需求和持续性 |
| 保留下一步选择 | 积累技能、信誉、信息与可信关系 | 个人积累并不能消除全部结构性限制 |
| 建立环境与正反馈 | 降低启动阻力，定期复盘 | 不靠透支身体或否定自身维持行动 |
| 善意与边界并存 | 清楚区分责任，允许拒绝 | 不把所有关系简化为敌对或交易 |
| 用过去校准未来 | 记录旧判断、发生的新事实与修订 | 不让单次事件决定永久身份 |

## 两份文本的关键区别

初版强调“解决—管理—接受”；扩展版增加“退出”，指出某些长期损害环境不能仅被包装为需要忍耐。扩展版也增加可逆/难逆决策区分及作品、社交、健康等建议的限制条件。

## 与这个仓库的关系

每周完成至少一个问题—证据—机制—边界—下一步的完整条目。仓库价值应以能否检索旧证据、修正判断、完成新作品来衡量，而不是以文件数量衡量。
