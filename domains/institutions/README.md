# 制度与权力

研究主问题：谁控制关键资源、准入规则和解释权？具体规则为什么使某些行为反复出现？

入口：[资源入口与权力转移](resource-gates.md)；案例：[公共资源](../../cases/public-resource-allocation.md)、[制度激励](../../cases/institutional-incentives.md)、[劳动谈判](../../cases/labor-bargaining.md)、[财政改革](../../cases/fiscal-reform.md)。

共用方法：正式目标 → 准入与分配 → 执行者的激励/约束 → 实际行为 → 可观察结果 → 监督、救济与修订。制度设计缺陷、执行偏差、已证实违规和未经证实的猜测必须分开。
