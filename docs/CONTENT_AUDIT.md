# Thinking Atlas 内容质量与证据缺口审计

审计日期：**2026-11-21**。审计基准：原仓库 `main` 的 14 份研究性正文、七个研究领域，以及页面迁移时保存的 `source.md`、`evidence.json`。此文件旨在明确**已做了什么、没有做什么、下一步先验证什么**，不是对所有历史、法律、经济观点的背书。

## 执行结论

- **结构层面**：14 个主题均获得可访问的 HTML、原始 Markdown、独立 SVG 和可追溯证据文件；单一分类清单驱动全站页面、归档、索引和 RSS。
- **研究层面**：现有 **8 篇「部分核验」、6 篇「研究提纲」、0 篇「全面核实」**。页面整理成功不等于原论断都真实。
- **已新增的核对**：劳务派遣（法律同工同酬、岗位范围、10% 口径、2025 年具体司法个案）和高平陵之变（《三国志》正文与裴注引《世语》的文献归属），已将具体事实写进相关 `evidence.json.verified_claims` 与正文。其他主题不能由此自动提升证据状态。
- **资料限制**：原始聊天并非完整导出；六份旧上传文本仅留有主题与主文档的映射，不意味着源文件、原始作者或原始写作时间已获验证。尤其不能以文件名猜测人物关系或来源性质。

## 后续核验的合格标准

每次研究增量至少要完成：①写明待检验的具体断言和适用时空；②定位原始资料及章节/统计表、发布日期、资料版本；③同口径寻找反例和独立来源；④标记支持、部分支持、争议、未证实或被反驳；⑤同步更新文章、`evidence.json`、内容注册表中的 `research_status`，并运行全站测试。

**不允许**把网站发布成功、SVG 图示美观、历史记录的存在、官方部门的观点、单一法院判例或对人物的合理推测，直接当作总体因果关系成立的证据。

## 内容治理与扩展

新增研究先寻找现有主分类和二级主题，避免重复创建不同标题下的同一结论。旧的问答主题不够成熟时可保留为明确标识的研究提纲；真正不相关、无法说明来源、涉及私人信息或无复用价值的材料不进入正式公开文章。源 Markdown 是历史底稿；修订证据时保留可比较的版本差异和审计记录。
