# 编辑与证据规范

**先确认事实，再设计图解。** 每篇文章从真实问题开始，区分事实、推论、假设与未知。研究过程和页面设计必须遵循 `skills/olah-style-paper-posts/SKILL.md`，但社会历史材料以公文、史料、司法原文、统计表、机构发布为主要一手依据。

## 证据状态
- VERIFIED：有可定位的一手文献或多源独立证据支撑，注明发布日期、时间、地点、适用范围与限制。
- PARTIAL：现有证据只支持部分细节或存在未解决范围问题。
- OUTLINE：仅有题目、来源摘要或未经本轮验证的故事，保留为待核查研究问题。

## 规范
- 标注来源取得时间，避免混淆法律生效、历史事件、材料写作与文章更新时间。
- 机制图说明变量与假设，不伪装为真实测量、比例或政策效力。
- 复杂主张寻找反证：替代解释、不同时间/口径、转载依赖、利益冲突、偏误与样本限制。
- `evidence.json` 记录原始路径、核验状态、可核验来源 URL；不能把迁移自动化算作证据核查。
- 研究提纲允许公开，但必须在首页、文章首屏和归档标记为“待核实”。
- 链接应指向可追溯的主资料，不使用虚构 DOI、案例号和页码。
- 来源中的私人身份信息或聊天原文不移入公开系统。
