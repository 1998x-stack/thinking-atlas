# 知识条目编辑规范

| 标记 | 必须写清 |
|---|---|
| `材料所述` | 源文本或可见提问中的观点与准确出处，不自动升格为事实 |
| `已核实事实` | 可定位的原始记录或可信研究、时间、地区和适用范围 |
| `解释/假设` | 由材料形成的机制、竞争解释与可反驳条件 |
| `行动/实验` | 下一次最低成本核查、数据整理或作品任务 |

主文档顺序：问题定义 → 已知材料 → 关键变量 → 候选机制 → 适用边界与反例 → 证据状态 → 验证路径 → 关联主题。

避免按日期复制同一观点；避免将时间先后直接写成因果；没有数据训练的指数权重、评分和风险概率不能称为测量结果；每个模型需一个边界或反例。重要判断变化时保留“旧判断 → 新证据 → 新判断”的修订记录。有关公众人物和公共政策的事实须查原始资料，不猜测动机。

每周整理顺序：收集可见资料 → 去重 → 根据主问题入域 → 标注证据状态 → 寻找失效条件 → 更新主文档 → 周索引补链接 → 推进一件可交付研究。
